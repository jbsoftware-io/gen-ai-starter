# Tutorial Zero (Optional) - The Prerequisites

### Sections
* Python
    * For general python course, check out the following:
        * Harvard CS department's free course [here](https://cs50.harvard.edu/python/2022/)
        * A good online book [here](https://thepythoncodingbook.com/book-outline/)
        * Interactive python learning guide `futurecoder` available [here](https://futurecoder.io/)
    * `pip` and `requirements.txt`
        * Official Getting Started for `pip` available [here](https://pip.pypa.io/en/stable/getting-started/)
    * Virtual Environments using `venv`
        * Official Docs available [here](https://docs.python.org/3/library/venv.html)
* Docker
    * Dockerfile Basics
        * Official Docs available [here](https://docs.docker.com/get-started/docker-concepts/building-images/writing-a-dockerfile/)
        * Hands-on Tutorial available [here](https://www.tutorialspoint.com/docker/docker_file.htm)
    * Docker Compose
        * Official Docs available [here](https://docs.docker.com/compose/)
    * Docker Workshop Tutorial
        * Practice using Docker and Docker Compose, available [here](https://docs.docker.com/get-started/workshop/)
* Large Language Models (LLMs)
    * Introduction
        * Google explains the basic concepts of LLMs available [here](https://developers.google.com/machine-learning/resources/intro-llms)
    * Open Source
        * IMB explains Open Source LLMs, pros/cons from paid models, and when they are most useful [here](https://www.ibm.com/think/topics/open-source-llms)
